# AI-Powered Sentiment Analysis System

Beginner-to-intermediate NLP + Machine Learning project based on the supplied Month 2 project brief and 10,000-review CSV dataset.

## Objective
Predict customer-review sentiment as **Positive**, **Negative**, or **Neutral**.

## Dataset
`data/reviews.csv` contains 10,000 records and these columns:
- `review_id`: review identifier
- `review_text`: text used as model input
- `sentiment`: target label
- `category`: product/service category
- `source`: feedback source

The supplied dataset has 10,000 rows, no missing values in the inspected columns, and a nearly balanced target distribution. The training script still performs basic cleaning before training.

## Project workflow
1. Load and clean the dataset.
2. Explore class distribution and review lengths.
3. Split data into train/test sets using stratification.
4. Convert text to TF-IDF features (unigrams and bigrams).
5. Train Logistic Regression and select hyperparameters using 3-fold cross-validation and GridSearchCV.
6. Evaluate on the held-out test set with accuracy, macro precision, macro recall, macro F1, classification report, and confusion matrix.
7. Save the full fitted scikit-learn pipeline.
8. Run a Streamlit app for new review predictions.

## Setup (Windows / VS Code)
1. Install Python 3.10 or newer.
2. Extract the project ZIP.
3. Open the extracted `sentiment-analysis-month2` folder in VS Code.
4. Open Terminal → New Terminal.
5. Create a virtual environment:
   ```bash
   python -m venv .venv
   ```
6. Activate it:
   - PowerShell: `.venv\\Scripts\\Activate.ps1`
   - Command Prompt: `.venv\\Scripts\\activate.bat`
7. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
8. Train the model:
   ```bash
   python train_model.py
   ```
   This creates the trained pipeline and evaluation outputs.
9. Start the web app:
   ```bash
   streamlit run app.py
   ```
10. Open the local URL shown in the terminal (commonly `http://localhost:8501`).

## Notebook
Open `notebooks/sentiment_analysis.ipynb` in Jupyter or VS Code. It covers data inspection, EDA, TF-IDF, model training, and evaluation.

## Metrics
Do not claim a performance score before training. Run `python train_model.py`; the script writes measured results to `reports/metrics.json` and `reports/classification_report.txt`.

## Important notes
- The held-out test set is kept separate from hyperparameter tuning.
- The confidence-like scores in Streamlit are model probabilities, not guarantees of correctness.
- The dataset may be synthetic or curated; performance on real-world reviews may differ.
- The project is educational and does not require deep learning, external AI APIs, or paid services.
